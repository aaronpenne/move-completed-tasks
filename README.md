# obsidian-move-completed

Moves completed tasks to the bottom of their checkbox group when you tick them off. Subtasks tag along. One undo to reverse.

## Install

Copy `main.js`, `manifest.json`, `styles.css` into `<vault>/.obsidian/plugins/obsidian-move-completed/` and enable in settings.

## Settings

- **Enable** — master toggle
- **Move with subtasks** — drag nested items along
- **Placement** — bottom of group, or just above already-completed items
- **Excluded characters** — checkbox chars that don't trigger a move (Minimal theme decorators by default: `?!*"lbiSIpcfkwud`)

## Notes

- Live Preview only (CM6 editor extension)
- Plays nice with the Tasks plugin
- Minimal theme alternative checkboxes stay put by default
